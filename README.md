# Satara Cafe (सातारा कॅफे) ☕️

> **An authentic, artisanal web application built for Satara Cafe in Sadar Bazar, Satara, Maharashtra.**  
> Crafted with an anti-corporate local-first aesthetic, bilingual (English & मराठी) support, interactive combo meal builder, real-time town rush clock, ambient cafe murmur synthesizer, and direct 1-click WhatsApp order dispatch.

## 🌿 Architectural Highlights & Features

1. **Warm Artisanal Palette & Organic Geometry**:
   - Soft Sand & Warm Ivory (`#FBF6EE`, `#FFFDF9`, `#F3E9D7`) canvas.
   - Sweeping Sage Green arch accents (`#758A6F`, `#E1EADA`, `#DCE6D8`).
   - Earthy terracotta action highlights (`#D37432`, `#B2581A`).
   - Deep espresso bark typography (`#241810`).

2. **7 Standalone Interactive Pages**:
   - **Page 1: Katta Home (`/home`)** — Sweeping hero arch, real-time Satara rush clock, Web Audio cafe chatter synthesizer, and daily specials.
   - **Page 2: Artisanal Menu (`/menu`)** — Full 7-category menu, dietary filters (Jain/Spicy), live keyword search, and the 3-step Katta Combo builder with auto-savings.
   - **Page 3: Order Slip & WhatsApp Dispatch (`/order-slip`)** — Authentic diner paper slip, spice levels & dine-in/takeaway toggles, 1-click WhatsApp order generator (`+91 75586 81179`), and printable receipt view.
   - **Page 4: Kitchen Craft & Spices (`/story-craft`)** — Interactive brass Masala Daba (6 clickable katoris), slow food philosophy, and authentic kitchen photo gallery.
   - **Page 5: Cafe Chits & Reviews (`/reviews`)** — Google Maps rating badge (3.9 ★, 212 reviews), dish filter tags, interactive like reactions, and *Pin a Review* submission modal.
   - **Page 6: Table Booking (`/table-booking`)** — Group breakfast/ride & katta table reservation desk with instant WhatsApp confirmation ticket.
   - **Page 7: Sadar Bazar Map & Guide (`/location`)** — Copyable Plus Code `M2R4+25`, interactive travel time estimator from 5 key Satara points, and local tourist guide.

3. **Bilingual Support (English & मराठी)**:
   - Instant 1-tap language switch across the entire website with native Marathi typography (*Rozha One*, *Yatra One*).

## 🛠️ Tech Stack

- **Framework**: React 19
- **Language**: TypeScript 5.x
- **Bundler**: Vite 8
- **Styling**: Tailwind CSS v4
- **Audio Synthesis**: Web Audio API (client-side brown/pink noise generator with warm low-pass filters)
- **Icons**: Lucide React
- **Typography**: Fraunces, Rozha One, Yatra One, Plus Jakarta Sans

## 🚀 Getting Started Locally

### 1. Clone the repository
```bash
git clone https://github.com/shreyaskumbhar4-hub/satara-cafe-website.git
cd satara-cafe-website
```

### 2. Install dependencies
```bash
npm install --legacy-peer-deps
```

### 3. Run development server
```bash
npm run dev
```
Open **`http://localhost:3000`** in your browser.

### 4. Build for production
```bash
npm run build
```
